# Kyodo Events — preview 0.2

Независимый от Kyodo сайт-каталог ивентов с оформлением под приложение, работающий на GitHub Pages. Основа — предыдущая версия HTML-календаря.

## Возможности

- верхняя панель с поиском, месяцами, годом и статусами;
- режимы карточек и календарной сетки;
- фильтр по **семи языковым сегментам** Кёдо: EN, ES, PT, FR, RU, DE, AR;
- по каждому ивенту: **название, период, язык, круг (и ссылка на него, когда есть) и рамка (когда доступна)**;
- статусы по датам «Скоро / В процессе / Прошёл»; «Отменён» — если календарь действительно отдаёт статус отмены;
- автоматическое обновление из публичного Google Календаря через GitHub Actions, без API-ключа;
- показ ивента в обоих месяцах, если период пересекает границу месяца.

Ссылки на отдельные публикации, этапы ивентов и хештеги намеренно удалены.

## Установка на GitHub Pages

1. Создай **новый публичный** репозиторий GitHub (или отдельную тестовую ветку); загрузи в корень **всё содержимое ZIP**, включая скрытую папку `.github` и папку `scripts`.
2. В **Settings → Pages** выбери **Deploy from a branch → main → / (root)**.
3. В **Actions** найди **Sync Official Kyodo Events!**, нажми **Run workflow**. Иногда требуется предварительно включить Actions для нового репозитория.
4. После успешного выполнения в репозитории появится `events.json`. Сайт начнёт использовать настоящие ивенты вместо встроенных демонстрационных.
5. Дальше расписание будет проверять изменения раз в **6 часов** (GitHub может задерживать запуск). Коммиты создаются только при изменении данных. При ошибке загрузки предыдущий `events.json` остаётся нетронутым.

Если GitHub сообщает `403`, `404` или «нет VEVENT», администратор календаря должен проверить доступ **Make available to public** с видимыми подробностями ивентов. Ссылки, где используется `private-...`/секрет, **не нужно** добавлять в публичный репозиторий.

## Изображения рамок

Календарь Google может показывать файл-приложение `Cover 1.1.png`, но **публичная iCal-лента не обязана передавать вложение**. Скрипт пробует достать прямую ссылку на картинку или публичную Google Drive-картинку из поля `ATTACH` (при наличии). Если ссылка не доступна всем или её нет в iCal, сайт честно показывает заглушку. Это не ошибка сайта.

Позднее можно добавить отдельный JSON с соответствиями рамок (по UID события), не затрагивая автоматическое получение названий, дат и языков.

## Что важно знать

- `DTEND` для целодневных событий в iCal — **исключительная дата**, а на сайте конец периода **включительный**.
- Отмена определяется по `STATUS:CANCELLED` или явной пометке в названии. Если событие просто удалили из исходного календаря, оно может исчезнуть из ленты, а не попасть в раздел «Отменён».
- Импорт настроен на одиночные ивенты. Сложные повторяющиеся события (`RRULE`) пока не разворачиваются по каждому повторению.
- `index.html` открывается локально с демонстрационными данными. В браузере на GitHub Pages он загружает файл `events.json`, когда он создан синхронизацией.
- **Это независимый проект**, не официальный сайт Kyodo. Не путать с оригинальным Google Календарём.
